# CALL TO ARTISTS

Native, local-first Android app. Free to build and use; no paid API dependencies.

## Features (prototype)
- Read publicly accessible opportunity URLs
- Manually record submission deadlines
- Save records locally
- Add events through Android Calendar
- Android home-screen deadline widget

## Build
GitHub Actions builds a debug APK on pushes to `main` or manual dispatch. Download the artifact from Actions. The APK is a prototype, not a production release.

## Limitations
Deadlines are not automatically extracted or independently verified. No scheduled crawling or deadline-change notifications yet. Respect site access policies.
